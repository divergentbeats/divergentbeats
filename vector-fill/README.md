<h2><a href="https://www.geeksforgeeks.org/problems/vector-fill/1">Array fill</a></h2>
<h3>Difficulty: Basic</h3>
<hr>
<div class="problem-statement">
<p><span style="font-size: 14pt;">Given an integer array <strong>arr[]</strong> and an integer <strong>k</strong>, fill the entire array with the value k such that every element of the array becomes equal to k.</span></p><p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p><pre><span style="font-size: 14pt;"><strong>Input: </strong>arr[] = [1, 2, 3, 4], k = 0
<strong>Output: </strong>[0, 0, 0, 0]
<strong>Explanation: </strong>Every element of the array is replaced with 0.</span></pre><pre><span style="font-size: 14pt;"><strong>Input: </strong>arr[] = [3, 2, 1], k = 7
<strong>Output: </strong>[7, 7, 7]
<strong>Explanation: </strong>Every element of the array is replaced with 7.</span></pre><pre><span style="font-size: 14pt;"><strong>Input: </strong>arr[] = [5], k = -2
<strong>Output: </strong>[-2]
<strong>Explanation: </strong>The single element in the array is replaced with -2.</span></pre>
</div>
